# Portafolio personal — Fabricio Miota

Portafolio estático construido con HTML y CSS, sin frameworks ni dependencias. Está preparado para publicarse con GitHub Pages.

## Antes de publicar

1. Abre `index.html` en VS Code y busca `TU_CORREO@EJEMPLO.COM`. Reemplázalo por tu correo en el texto y en el enlace `mailto:`.
2. Busca `51XXXXXXXXX` y reemplázalo por tu número de WhatsApp con código de país, solo números. Para Perú, empieza por `51`.
3. Revisa el texto de presentación y los servicios para que representen exactamente lo que ofreces.
4. La sección de proyectos indica honestamente que las demos están en preparación. Cuando tengas demos funcionales, sustituye ese texto por tarjetas con enlaces reales.

## Probar localmente

Abre `index.html` en un navegador. En VS Code también puedes usar una extensión de servidor local, pero no es necesaria para este sitio estático.

## Publicar con GitHub Pages

1. Crea un repositorio público llamado exactamente `FabricioMiotaT.github.io`.
2. Sube `index.html`, `styles.css` y `README.md` a la raíz de la rama `main`.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`, y guarda.
5. Espera a que termine la publicación y abre `https://fabriciomiotat.github.io/`.

GitHub Pages publica archivos estáticos; no ejecuta backends como PHP, Node.js ni Python.
